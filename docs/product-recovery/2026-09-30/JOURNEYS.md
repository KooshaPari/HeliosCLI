# Mature journeys — HeliosCLI

## J-HC-01 Interactive coding
Install/configure -> open repository -> start/resume thread -> inspect context -> model turn -> tools/edit/shell -> approvals -> verification -> evidence -> accepted result -> durable resume.

## J-HC-02 Headless automation
Structured assignment -> policy/config -> noninteractive run -> machine-readable events -> bounded tools -> verification -> deterministic exit/result/evidence.

## J-HC-03 Interrupted durable work
Start long task -> external effect -> worker/client loss -> reconnect/replacement -> durable state recovery -> reconcile uncertain effects -> continue without duplicate work -> final evidence.

## J-HC-04 Parallel work
Create isolated workspaces/worktrees -> launch multiple attempts/agents -> resource scheduling -> independent events/evidence -> compare/grade -> select/integrate accepted result.

## J-HC-05 Human intervention
Agent reaches approval/question/conflict -> client receives typed request -> user responds from any compatible client -> same durable effort resumes with provenance.

## J-HC-06 Client interchange
Begin in CLI/TUI -> disconnect -> inspect/control same effort from HeliosLab/API/other client -> return to CLI without semantic loss.

## J-HC-07 Provider/runtime substitution
Run equivalent accepted assignment across supported provider/model/runtime -> capability negotiation -> explicit degraded/unsupported behavior -> same harness evidence contract.

## J-HC-08 Update/coexistence
Install alongside upstream Codex/KCode as supported -> update/migrate config/state -> verify binary/runtime identity -> rollback if needed without corrupting shared work.

## Stage projection
CVP: J-HC-01 narrow + J-HC-02 narrow with real harness spine.
MVP: add J-HC-03/J-HC-05 and supported provider/tool breadth.
Beta: add J-HC-04/J-HC-06/J-HC-08 with reliability/performance gates.
GA: all required journeys close under release/security/upgrade/compatibility evidence.
Mature: generic harness interoperability and high-scale QoS proven; clients remain replaceable.
